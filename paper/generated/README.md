# Generated paper tables

The `icra_*.tex` files are the canonical table inputs compiled by `paper.tex`.
Regenerate them with `scripts/build_icra_evidence_bundle.py` using the canonical
evidence inputs; do not edit generated tables manually.

The `paper_*.tex` files are legacy compatibility outputs retained for provenance
only. They are not included by the current manuscript and must not be used as
submission sources.
